# PowerShell(Windows)

## Install TypeScript Globally

```bash
npm install -g typescript
```

## Run Code

```bash
tsc <filename>
```

# Install And manage different types of Node Version

```bash
winget install Schniz.fnm
```

```bash
fnm install <version name you want to install>
```

### Verify the Node.js version:

```bash
node -v
```

##### Should print "v22.15.0".

##### Verify npm version:

npm -v

##### Should print "Your Node versions".
